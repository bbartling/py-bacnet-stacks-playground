- Do not invent video content that has not been transcribed.
- Store transcripts under `docs/transcripts/` only when obtained lawfully from available captions or user-provided text.
- Preserve timestamps and video URL in transcript metadata.
- Convert video guidance into a skill only after comparing it with current public documentation.
- When video and current documentation conflict, prefer the newer documentation and record the discrepancy.
