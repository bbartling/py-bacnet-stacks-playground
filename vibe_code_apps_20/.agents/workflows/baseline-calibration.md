# Baseline Calibration Workflow

Sketchbox is primarily a conceptual tool; calibration must not be implied automatically.

1. Define the calibration target and available bills.
2. Normalize billing periods and weather.
3. Confirm area, schedule, fuels, and major process loads.
4. Adjust only parameters with physical evidence.
5. Keep a change log and avoid compensating errors.
6. Report calibration statistics only when calculated correctly.
7. Label uncalibrated runs as conceptual screening.
