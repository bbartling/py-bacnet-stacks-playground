# HVAC Mapping

## Purpose
Map actual HVAC into the nearest defensible Sketchbox configuration.

## Invoke when
Creating baseline systems or system-switch measures.

## Required inputs
- System diagrams
- equipment schedules
- heating fuel
- cooling source
- air-side type
- DOAS/ventilation arrangement
- controls

## Procedure
1. Describe actual system functionally.
2. Select closest supported representation.
3. List matched and unmatched characteristics.
4. Map efficiencies and fan power.
5. Add approximation limitation.

## Outputs
- HVAC mapping table
- unsupported-feature list
- approved approximation

## Guardrails
Never label an approximation as exact. Preserve heating fuel and ventilation delivery distinctions.

## Validation
Reviewer confirms causal fidelity for the ECMs being tested.
