# ECM Portfolio

## Purpose
Rank approved individual ECMs while preserving interaction caveats.

## Invoke when
Comparing multiple measures or building a project pipeline.

## Required inputs
- Validated individual results
- costs
- confidence
- implementation constraints
- interactions

## Procedure
1. Score savings, payback, confidence, persistence, complexity, and prerequisites.
2. Identify mutually dependent/conflicting measures.
3. Separate no/low-cost from capital work.
4. Produce implementation sequence.
5. Do not sum interactive savings as a package estimate.

## Outputs
- ranked portfolio
- interaction matrix
- implementation roadmap

## Guardrails
Individual progressive savings are not automatically additive.

## Validation
Every ranking factor is traceable and interaction warnings are visible.
