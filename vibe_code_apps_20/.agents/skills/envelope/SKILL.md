# Envelope and Glazing

## Purpose
Translate evidence of wall/roof/window performance scenarios into a defensible individual ECM.

## Invoke when
When evidence suggests wall/roof/window performance scenarios.

## Required inputs
- areas, U-values, SHGC, WWR by faÃ§ade, infiltration
- approved baseline
- implementation constraints

## Procedure
1. Validate sensors and prerequisites.
2. Confirm applicability and causal mechanism.
3. Quantify affected hours/loads without double counting.
4. Define exact baseline and proposed inputs.
5. Preserve geometry and orientation; do not use glazing percentage alone to infer thermal performance.
6. Create MeasureBrief and verification plan.

## Outputs
- ECM brief
- EnergyPlus parameter map
- implementation and verification notes

## Guardrails
Do not report savings when prerequisites fail. Keep non-energy benefits separate from modeled energy.

## Validation
Evidence chain complete; parameter mapping reviewed; result passes QA.
