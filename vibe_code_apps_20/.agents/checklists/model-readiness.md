# Model Readiness Checklist

- [ ] Project is marked anonymized or non-anonymized.
- [ ] Conditioned floor area is known.
- [ ] Climate city and energy-code baseline are selected or explicitly unknown.
- [ ] Shell partition rationale is documented.
- [ ] Program, HVAC, and schedule are defined per shell.
- [ ] Window-to-wall ratio is recorded by façade when available.
- [ ] Baseline versus proposed distinction is clear.
- [ ] Utility rates and emissions assumptions are documented if reporting economics/carbon.
- [ ] Unsupported systems have an approved approximation note.
- [ ] Baseline hash and input manifest are created.
