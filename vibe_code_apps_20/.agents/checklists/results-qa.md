# Results QA Checklist

- [ ] Baseline run completed without model errors.
- [ ] Measure input hash matches approved brief.
- [ ] Annual totals reconcile with monthly totals within tolerance.
- [ ] Savings sign is physically plausible.
- [ ] End-use direction matches the measure mechanism.
- [ ] No baseline parameter leaked into the proposed case unintentionally.
- [ ] Savings are not double counted across reported ECMs.
- [ ] EUI and savings intensity are within screening bounds or explained.
- [ ] Cost and emissions calculations use documented factors.
- [ ] Result is labeled conceptual unless calibrated.
