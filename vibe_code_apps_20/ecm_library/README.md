# ECM Library

Each ECM is implemented as a skill under `.agents/skills/`. Add new ECMs only when they have:

- required evidence and sensor prerequisites;
- applicability and exclusion rules;
- exact baseline/proposed parameter mapping;
- interaction notes;
- implementation and verification guidance;
- result QA expectations.

Initial catalog:
- schedule optimization
- economizer repair
- SAT reset
- duct static reset
- VAV minimum-flow reset
- fan-power improvement
- lighting
- envelope and glazing
- plant efficiency
- HVAC system switch
