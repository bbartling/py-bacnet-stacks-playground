Open-FDD / Vibe Code App 19 — RCx DOCX Template Pack

Purpose
-------
These are engineer-edited Word templates intended to be served by the Streamlit app as static downloads.
The workflow is intentionally manual:
1. Run analytics and tune filters/thresholds in Streamlit.
2. Download or screenshot the Plotly chart.
3. Paste the chart into the matching placeholder.
4. Copy fault hours, percentages, equations, operating gates, and notes into the tables.
5. Finish the client narrative and issue the report.
