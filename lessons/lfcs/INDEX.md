# LFCS 50-day crash course (Raspberry Pi friendly)
| Item | Link |
| --- | --- |
| **Daily lessons** | `day01.md` … `day50.md` |
| **Syllabus in README** | [LFCS section](../../README.md#lfcs-50-day-crash-course) |
| **Exam domains** | Operations 25% · Networking 25% · Storage 20% · Essential Commands 20% · Users/Groups 10% |

Short daily labs in the same format as [`../day31.md`](../day31.md). Run on a **Raspberry Pi** (Pi OS) or any Linux VM. Prefer a **snapshot** before storage/network experiments.

**How to use:** clone the repo → open one `dayNN.md` per day → run the commands in a terminal → do the micro exercises. About **20–40 minutes** per day.
