# Lessons index (Days 1–68)

Daily mini-lessons live in this folder as `dayNN.md`. The **Weekly Outline** in the repo [README.md](../README.md#weekly-outline) is the canonical syllabus text; this page is a **compact link hub**.

**Conventions:** Early days avoid list/dict comprehensions. **Days 41–68** introduce tuples, sets, nested dicts, RDF/Turtle/`rdflib`, Brick, and SPARQL as needed for smart-building **data modeling** (not a full graph-algorithms course).
