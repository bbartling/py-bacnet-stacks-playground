# Linux training — OverTheWire Bandit

We use **[OverTheWire Bandit](https://overthewire.org/wargames/bandit/)** for Linux / shell fundamentals instead of a local LFCS day pack.

## How this track works

- **Play the game** on the Bandit site: start at [Level 0](https://overthewire.org/wargames/bandit/bandit0.html) and work upward.
- **Daily challenges** are posted on **[Discord](https://discord.gg/Ta48yQF8fC)** — same cadence as the Python and Rust lesson posts.
- Bring questions, screenshots of stuck levels, and `man` / `help` discoveries to Discord.

## Why Bandit

Bandit is aimed at absolute beginners and teaches the command-line basics you need for everything else in this repo (SSH, files, permissions, pipes, processes). Official intro: [OverTheWire Bandit](https://overthewire.org/wargames/bandit/).

## Tip when stuck

Use `man <command>`, `help <builtin>`, and search — panic is optional; reading is not. See the Bandit “Note for beginners” on the site above.
