# Validation and release

Run the narrowest deterministic checks that cover changed code and data contracts, then integration checks for model/tool paths when available. Verify schemas, artifact existence, IDs/hashes, unit and interval semantics, safety labels, and claims against source artifacts.

Distinguish unavailable external/model runs from passing runs. Do not replace a failed physical or calibration gate with a passing smoke test. Preserve privacy scans and review any anonymized report/screenshot before publication.
