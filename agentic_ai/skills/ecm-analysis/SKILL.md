# ECM analysis

Use for schedule, economizer, fan-power, static-pressure, SAT, VAV-minimum, lighting, envelope, plant-efficiency, or HVAC-system measures.

- Establish an approved baseline and one reviewable measure definition before editing the model.
- Use actual evidence and an appropriate proxy only; label unmodeled sequence details and non-energy benefits.
- Assess interactions, prerequisites, implementation risk, persistence, confidence, costs, incentives, and M&V needs.
- Rank individual measures transparently. Do not add individual savings into a package estimate unless the package is modeled under its own frozen contract.

Use `evidence-and-measures` to author the intervention, `energy-economics` for economics, and `energyplus-results` for simulation QA.
