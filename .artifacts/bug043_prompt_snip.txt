## Mission

Flip vibe20 ECMs from “dashboard + Advanced Easy Buttons” to **Excel-as-contract**:

1. **Pooge** Advanced Easy Buttons / measure-set editors / capital-plan walls / client DOCX from the ECMs page (BUG-043).  
2. Make notebooks **AI-agent friendly**: agents edit Inputs + formula cells, **refresh** cached values, humans see **formulas and values** in Streamlit and download the same `.xlsx` (BUG-044).  
3. Enable / document **`wattlab easy-button` EP cascade** so full packages get `savings_by_measure` (BUG-045) — Docker socket + EnergyPlus image on bensbench-style hosts.  
4. Keep moving toward real Excel ESCO blocks where practical (BUG-046); do not pretend baked kWh are formulas.

**Success look-and-feel**

- ECMs tab: pick package → build/refresh → Values + Formulas preview → download `.xlsx` + manifest.  
- Agent produces Liberty packages 1…5 as five files with no Easy Button clicks.  
- Engineer (or agent) changes `$/kWh`, coverage, or a formula; refresh updates caches; UI shows the Excel formula text.  
- With EP cascade wired, Compare is not stuck all-YELLOW for want of `savings_by_measure`.

```bash

  --from-run /data/runs/<published_easy_button_run> \
  --out /data/reports/notebooks/
```
