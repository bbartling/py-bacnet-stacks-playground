📋 How to Deploy & Connect to Niagara 4 Station ▼ Click to expand
  1. Open Niagara 4 Workbench and connect to your station.
  2. In the Nav tree, go to: Your Station → Files. Right-click Files → New Folder → name it html (if it doesn't exist).
  3. Right-click the html folder → Import File(s) → select this HTML file → click OK.
  4. Open a browser on any computer on the same network and go to:
    https://<your-station-IP>/file/html/GL36_Central_Plant_Graphic.html
  5. Log in with your Niagara username and password when prompted.
  6. The page will auto-connect to live data. The green dot above means WebSocket is active. Yellow means polling mode (still works, updates every 10s).
  7. If you see red dot: check that the slot path station:|slot:/BBartling/GL36_CENTRAL_PLANT exists in your station.
