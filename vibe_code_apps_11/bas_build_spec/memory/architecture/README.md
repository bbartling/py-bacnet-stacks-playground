# Working architecture vs spec/skills

Append-only log when **implemented** behavior in `bas_app/` or automation **differs** from `spec.md`, `acceptance_criteria.md`, or `skills/*/SKILL.md` because the documented path failed or was incomplete.

**File:** `working-divergence.md` (same folder).

**Mini:** append one dated block when you discover a durable mismatch during a slice.

**Critique:** triage new entries; promote stable patterns into `skills/*/references/` or `MEMORY.md`; mark entries `promoted` or `superseded` in the log.

Do not log secrets, credentials, or full spec pastes.
