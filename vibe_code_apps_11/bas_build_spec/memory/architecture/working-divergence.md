# Working architecture divergence log

Append when live code or ops **work** but **spec/skills** are wrong, incomplete, or untested. Feeds skill and spec improvements; not a second task queue.

## Entry template

```markdown
## YYYY-MM-DDTHH:MMZ — short title

- **Status:** open | promoted | superseded
- **Expectation (spec/skill):** path + one-line claim
- **Working reality:** what actually runs
- **Evidence:** paths, commands, smoke, journal
- **Skill/spec follow-up:** optional target file
```
